← 터놓고로 돌아가기

개인정보처리방침 · 면책 안내

터놓고(https://local-rader.github.io)는 공공데이터로 청주시 건축 인허가 정보를 보여주는 비공식 서비스입니다. 회원가입이 없고, 이름·연락처·주민등록번호 같은 개인정보를 받지 않습니다.

1. 사이트가 저장하는 정보

이 사이트는 방문자의 기기(브라우저)에만 다음 설정을 저장합니다. 이 설정은 서버로 보내지 않습니다. (AI 질문을 쓸 때 전달되는 내용은 아래 2번을 보세요.)

항목내용보관 위치
관심 필지표시해 둔 필지 번호브라우저 저장소 (직접 지우기 전까지)
화면 설정기간, 동네, 정렬, 원 크기, 비교할 지역 등브라우저 저장소
AI 질문 기기 번호AI 질문 횟수를 세기 위한 무작위 번호 (이름·연락처와 연결되지 않음)브라우저 저장소
방문 표시오늘 방문을 이미 셌는지 표시하는 날짜 (하루에 한 번만 세기 위함)브라우저 저장소

주소를 지도 위치로 바꾼 결과는 화면이 열려 있는 동안만 기기 메모리에 두며, 브라우저에 오래 저장하지 않습니다.

2. 외부 서비스

  • 카카오맵: 지도를 불러오기 위해 카카오 서버에 접속합니다. 이때 접속 기기의 IP 주소 등 기본 접속 정보가 카카오에 전달될 수 있습니다. 카카오의 개인정보 처리는 카카오 정책을 따릅니다.
  • GitHub Pages: 이 사이트를 호스팅합니다. 접속 기록은 GitHub 정책을 따릅니다.
  • AI 질문 (Cloudflare, Anthropic): 'AI 질문' 화면에서 직접 쓴 질문을 보내면, 질문 내용과 고른 동네가 중계 서버(Cloudflare Workers)를 거쳐 Anthropic의 Claude로 전달되어 답을 만듭니다. 터놓고는 질문과 답을 저장하지 않습니다. 질문 횟수를 세기 위해 기기 번호와 접속 IP 주소를 한 방향 암호(해시)로 바꾼 값과 횟수만 최대 8일 보관합니다. 전달된 내용의 처리는 Cloudflare와 Anthropic의 정책을 따릅니다. 질문 버튼은 기기 안에서 계산하므로 외부로 보내지 않습니다.

AI 질문창에는 이름, 연락처, 주민등록번호 같은 개인정보를 적지 마세요.

방문 통계: 사이트 운영을 위해 브라우저마다 하루 한 번, 방문했다는 사실과 들어온 사이트 이름(예: instagram.com, 검색 사이트), 기기 종류(휴대폰·태블릿·PC)만 위의 중계 서버(Cloudflare Workers)로 보내 합계를 냅니다. 기기 번호, IP 주소, 방문한 화면과 전체 주소는 저장하지 않으며, 기록은 400일 뒤 자동으로 지워집니다.

이 사이트는 외부 방문 분석 도구나 광고 쿠키를 사용하지 않습니다.

3. 개인정보 보호 요청

브라우저 저장소에 남은 설정은 브라우저의 사이트 데이터 삭제 기능으로 지울 수 있습니다. 그 밖의 문의나 정정 요청은 GitHub 이슈 페이지에 남겨 주세요.

4. 자료의 출처와 이용 조건

  • 건축 인허가 자료: 국토교통부 건축HUB 건축인허가정보 서비스(공공데이터포털).
  • 필지 위치·개별공시지가: 국토교통부 브이월드 2D데이터 API (공공누리 제1유형).
  • 지도: 카카오맵.
  • 건물 이름은 시설 이름으로 보이는 것만 남기고, 개인 이름이 들어갈 수 있는 것은 지웠습니다.

5. 면책

  • 이 사이트는 개인이 공공데이터를 모아 만든 참고용 서비스입니다. 정부 기관과 관련이 없습니다.
  • 자료는 공공데이터의 반영 시차가 있어 실제 상황과 다를 수 있습니다.
  • 투자, 거래, 법적 판단의 근거로 쓰지 마세요. 정확한 내용은 세움터에서 대지위치로 다시 확인하세요.
  • 개별공시지가는 시세가 아닙니다.
  • AI 답변은 틀릴 수 있으며, 투자·거래·법적 판단의 근거가 아닙니다.
